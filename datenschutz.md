# Datenschutzerklärung – StanDart

**StanDart** speichert Spielstände, Einstellungen, Spielerprofile und heruntergeladene Song-Vorschauen ausschliesslich lokal auf dem Gerät. Es werden keine Nutzerkonten angelegt und keine personenbezogenen Daten an eigene Server übertragen.

Bei der optionalen Suche nach Einlaufsongs werden Suchbegriffe direkt vom Gerät an die öffentliche API von **Deezer** (deezer.com) gesendet, um Titelinformationen und 30-Sekunden-Vorschauen abzurufen.
